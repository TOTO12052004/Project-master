# 💬 Project Chatting Online

Project ini merupakan website chatting online yang dibuat menggunakan HTML, CSS, JavaScript, dan Bootstrap.

## 📌 Fitur

- 🔐 Login
- 📝 Registrasi
- 💬 Chatting online
- 👤 Profile pengguna
- 🔎 Pencarian kontak
- 📎 Attachment
- 😊 Emoji
- 📱 Responsive design
